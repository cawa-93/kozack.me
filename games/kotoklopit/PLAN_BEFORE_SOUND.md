# План перед звуком

## Контекст

Перед роботою зі звуком автор хоче поправити чотири речі: менше знижок, дорожчі якісні товари й автоматика, віник замість стартового пилососа, сильніші й різні роботи, перестановка речей гравцем. Мета: гроші справді ведуть гравця від дешевого до дорогого, а квартиру можна облаштувати під себе.

Файл тимчасовий: коли роботу закінчено, чинне вже в `GAME_DESIGN.md`, а файл видаляємо. Етапи робимо по одному, кожен запускає автор.

## Етап 5. Завершення

- Увесь набір тестів, `npm run build -w games/kotoklopit`, повний баланс (`BALANCE_WEEKS=20`) із комітом `REPORT.md`.
- Звірити, що все чинне вже в `GAME_DESIGN.md`, видалити `PLAN_BEFORE_SOUND.md`, переписати §12: далі — звук.

## Порядок роботи

- Кожен етап — блок: спершу документ, потім код, логічні зміни окремими комітами, §12 наприкінці.
- Під час роботи — `npm run typecheck -w games/kotoklopit` і тести ділянки. Увесь набір — наприкінці етапу.
- Один пуш на завершений етап, щоб автор подивився на прев'ю. Після етапу — що перевірити очима.
- Етапи йдуть послідовно, бо чіпають ті самі файли (`economy.ts`, `actions.ts`, `types.ts`). Паралельно — лише всередині етапу, наприклад арт і симуляція в окремих worktree.
